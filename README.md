# 黑金神秘塔罗抽卡网页

一个纯前端塔罗体验页，包含：

- 首屏提问：「你想要问什么问题？」
- 选择一次抽取 3~5 张牌
- 78 张塔罗牌先打乱，再以漂浮散落的方式铺在可横向浏览的牌阵中
- 非触屏手势交互（摄像头 + MediaPipe Hands）
  - 手掌左右滑动：浏览牌阵
  - 指尖指向：锁定想选的卡牌
  - 指尖向上滑动：抽出该牌
- 支持正位 / 逆位
- 按问题 + 全部抽牌结果生成个性化文本解读

## 运行

```bash
python3 -m http.server 4173
```

访问 `http://localhost:4173`，并允许浏览器使用摄像头。
